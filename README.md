# 등불 영지 — 이계의 영주

교통사고로 이세계에 떨어진 20대 후반 회사원 세진이 산골 마을 "등불골"을 지키고 키우면서, 동료들과 던전을 돌며 집으로 돌아갈 길을 찾는 영지 경영 + 자동전투 RPG.
모바일(안드로이드) 웹앱(PWA)이에요.

- `design/` 설계 문서(스토리, 전투, 직업, 캐릭터, 파고들기 시스템, Codex 아트 프롬프트)
