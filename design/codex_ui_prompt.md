C:\CLAUDE\FIEF 에 있는 모바일 웹 게임 「등불 영지 — 이계의 영주」의 UI를 전반적으로 다듬어 줘. 게임 로직은 건드리지 말고, 화면의 완성도를 상용 모바일 JRPG 수준으로 끌어올리는 것이 목표야.

## 게임 소개
- 이세계 산골 마을을 키우는 영지 경영 + 자동전투 RPG. 20대 후반 회사원 세진이 이세계에 떨어져 마을을 지키고 키운다.
- 하루 단위 진행: 낮에 건설·일꾼·모집·상점·원정, 밤에 몬스터 습격.
- 전투: 왼쪽 아군 / 오른쪽 적의 사이드뷰 JRPG. 진형은 전열·후열 × 5줄. 캐릭터 그림은 정지 이미지이고, CSS/WAAPI 애니메이션으로 움직인다.
- 폰 세로 화면(안드로이드 크롬) 전용 PWA. GitHub Pages로 배포: https://sejin0523.github.io/lantern-fief/

## 코드 구조 (빌드 없음, 바닐라 JS, 전역 함수)
- index.html: 스크립트 순서 art → data → units → battle → game → story → battleview → ui → main
- style.css: 모든 스타일
- js/ui.js: 타이틀, 대화, 마을 허브(마을/동료/편성/원정 탭), 동료 상세 시트, 결과 모달, 토스트
- js/battleview.js: 전투 화면 렌더링과 연출(정지 이미지 이동·번쩍임·투사체·데미지 숫자·배너)
- js/main.js: 버튼 동작(ACT 객체). 클릭은 `data-act` / `data-arg` / `data-tab` 속성으로 위임 처리
- js/art.js: `ART` 객체(그림 키 → 경로). 지금은 비어 있고, 그림이 없으면 임시 그림(CSS 실루엣, 이모지)으로 대체된다
- js/data.js, units.js, battle.js, game.js, story.js: 게임 데이터와 로직
- 폰트: fonts/Galmuri11.woff2 (도트 한글 폰트, 계속 사용)

## 수정 범위
- 고쳐도 되는 것: style.css, js/ui.js, js/battleview.js, index.html(메타·구조), 새 이미지(art/ui/ 아래)
- 고치면 안 되는 것: data.js, units.js, battle.js, game.js, story.js의 로직과 수치. 세이브 형식(G 객체). main.js의 ACT 동작
  - main.js는 새 버튼을 연결할 때만 최소한으로 고친다
- 반드시 유지할 것:
  - `data-act`, `data-arg`, `data-tab` 속성과 그 값(main.js가 이것으로 동작한다)
  - 함수 이름과 시그니처: showTitle, playScenes, playScene, showHub, renderTab, showDetail, showEquipPicker, showResult, rewardLines, closeModal, toast, playBattle, unitSprite, monSprite, ic, scenery
  - 그림 대체 규칙: `ART[key]`가 있으면 그 그림, 없으면 지금처럼 CSS/이모지 대체. 그림이 하나도 없어도 화면이 깨지면 안 된다
  - UI 아이콘 키: ui.js의 `ICON` 표(ui_icons_a_1 … ui_icons_b_24). 나중에 아이콘 시트가 들어오면 자동으로 바뀐다
- 외부 라이브러리·CDN·프레임워크 금지. 오프라인에서 돌아가야 한다
- 코드가 바뀌면 sw.js의 VERSION 숫자를 하나 올린다(fief-v3 등)

## 디자인 방향
- 톤: 따뜻한 등불빛이 감도는 다크 판타지. 남색·먹색 바탕에 금색·호박색 포인트, 나무와 양피지 질감
- 기준: 도트 그래픽 모바일 JRPG의 정돈된 UI. 화려하되 읽기 쉽게
- 공통 컴포넌트를 먼저 정리하고 모든 화면에 일관되게 적용한다
  - 패널 프레임: 나무 또는 금속 테두리 느낌의 9-slice. CSS `border-image`나 다중 그림자로 구현하거나, 필요하면 도트 프레임 이미지를 직접 생성해서 art/ui/에 넣는다
  - 버튼: 기본, 강조(금색), 위험, 비활성 상태가 분명해야 한다. 누를 때 눌림 효과
  - 탭과 세그먼트, 태그와 뱃지, 진행 바(HP·경험치·지휘 게이지), 자원 표시, 모달 시트
- 여백·글자 크기·둥근 모서리·그림자를 스케일로 정해서 통일한다
- 모바일 규칙:
  - 터치 영역 최소 44px
  - 본문 글자 13px 이상, 보조 글자 11px 이상
  - 360px 폭에서도 가로 스크롤이 없어야 한다
  - 아이폰 노치·안드로이드 제스처바 safe-area를 고려한다
- 움직임: 화면·탭 전환, 모달 등장, 버튼 눌림, 전직·레벨업 강조 같은 짧은 애니메이션. 과하지 않게, 중저가 폰에서도 부드럽게
- 한국어 문구는 그대로 둔다. 어색하게 잘리는 곳만 레이아웃으로 해결한다

## 화면별 요청
1. 타이틀: 지금은 CSS 산 그림에 글자만 있어서 허전하다. 로고 타이틀, 등불 빛 효과, 배경 연출을 다듬는다. 전용 그림은 나중에 따로 만들 예정이니 그림이 들어갈 자리를 남겨 둔다
2. 대화(스토리): 이름표, 대사 상자, 다음 표시, 건너뛰기, 화자 그림 배치를 비주얼노벨처럼 보기 좋게
3. 마을 허브
   - 위 배너(마을 풍경, 날짜 명패, 장 이름, 인구·사기)
   - 자원 바(금화·식량·목재·석재와 하루 증감)
   - 습격 경고 띠, 목표 카드
   - 하위 메뉴(건설/일꾼/모집/상점/기록)
   - 아래 탭 바(가운데 "하루 마치기" 달 버튼)
4. 건물 타일: 레벨 칸, 비용, 건설 가능·불가 이유, 최대 레벨 상태를 한눈에
5. 모집 카드·동료 카드: 초상 영역, 이름, 종족·직업·레벨, 특성 태그, 상태(부상·지침·전직 가능), 전투력
6. 편성: 전장 느낌의 2열 × 5줄 배치판과 대기 동료 목록. 고른 상태와 이동 가능한 칸이 분명히 보이게
7. 원정: 던전 카드와 층 경로(1층 → 보스), 권장 레벨, 잠김·클리어·다음 층 상태, 출전 파티 요약
8. 동료 상세 시트
   - 초상과 이름, 직업 뱃지, 레벨·경험치
   - 능력 / 특성 / 장비 / 기술 탭
   - 잠재력 등급은 F~S, ★ 색 구분
   - 고유 무기 강화 버튼, 전직 선택
9. 전투 화면
   - 상단: 제목, 배속, 결과 보기, 행동 순서 줄
   - 전장의 바닥과 깊이감, 캐릭터 그림자, HP 바(보호막 표시 포함), 이름표
   - 연출: 데미지 숫자, 치명타·회피·회복 팝업, 스킬 이름 배너, 승리·패배 연출
   - 하단: 세진의 지휘 게이지와 버튼 3개, 작전 선택
   - 연출 타이밍과 로직(playEvent의 순서)은 유지하고 보이는 것만 다듬는다
10. 결과 모달, 토스트, 장비 선택 시트도 같은 스타일로
