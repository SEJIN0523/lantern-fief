# 직업 트리 (v2, 2026-10-27)

역할 기호:
- 방탱 = 방어탱커, 회탱 = 회피탱커, 마탱 = 보호막 탱커
- 근딜 = 근거리 딜러, 원딜 = 원거리 딜러, 마딜 = 마법 딜러
- 힐 = 회복, 버프, 디버프, 특수
- 레벨 상한 9999(환생 시스템, endgame.md). 전직 조건: 2차는 레벨 20, 3차는 레벨 50 + 계열 조건(예: 회피 50회). 환생하면 다른 계열로 갈아탈 수 있고, 익힌 스킬은 계승 슬롯으로 가져감.
- 평민(0차, 마을 주민 출신): 레벨 10에 원하는 1차 직업으로 전직. 특성에 따라 적성 보너스가 붙음.

## 전사 (모험가 길드)
1차 전사 (근딜/방탱 겸용)
- 기사 (방탱: 수호, 방패막기) → 성채기사 (방탱: 방벽, 피해 반사) / 성기사 (방탱+힐: 신성 방패, 자가 치유)
- 검사 (근딜: 연속베기, 반격) → 검성 (근딜: 단일 극딜, 일섬)
- 광전사 (근딜: 체력이 낮을수록 강해짐) → 전쟁군주 (근딜+버프: 광역 베기, 아군 공격력 함성)

## 병사 (마을 병사 모집 — 저렴, 충성 높음, 녹색·황갈색 마을 군복)
1차 창병 (관통 찌르기)
- 방진병 (방탱: 같은 줄 후열 완전 보호, 넉백 무시) → 근위대장 (방탱+버프: 전열 전체 방어 오라)
- 미늘창병 (근딜: 줄 관통, 기병 특효) → 용기병 (근딜: 도약해서 후열 직접 공격, 도약 중 무적)
- 공병 (특수: 바리케이드·함정 설치, 마을 건설 속도 +) → 공성기술자 (특수: 포탑 설치, 성벽 방어전 강화)

## 도적 (모험가 길드)
1차 도적 (근딜: 회피, 훔치기)
- 결투가 (회탱: 도발 + 높은 회피 + 회피 시 반격) → 칼날무희 (회탱: 회피할 때마다 반격이 연쇄되고 회피 스택)
- 암살자 (근딜/원딜: 후열 저격, 첫 턴 확정 치명) → 그림자칼날 (근딜: 은신, 처치 시 재행동)
- 척후병 (특수: 선제, 적 정보 공개, 전리품 +) → 길잡이 (특수: 던전 함정 해제, 탐색 이벤트 유리, 아군 속도 +)

## 궁수 (모험가 길드, 사냥꾼 주민)
1차 궁수 (원딜)
- 레인저 (원딜: 지속 사격, 연사) → 매의 눈 (원딜: 치명 저격, 방어 무시)
- 사냥꾼 (디버프: 덫, 출혈, 짐승 특효) → 마물 사냥꾼 (원딜: 보스 특효, 약점 노출)
- 석궁병 (원딜: 관통 볼트, 갑옷 파괴) → 공성사수 (원딜: 열 전체 관통 사격)

## 마법사 (모험가 길드, 마탑)
1차 견습 마법사 (마딜)
- 원소술사 (마딜: 속성 광역) → 대마법사 (마딜: 전체 마법, 원소 연쇄)
- 흑마법사 (디버프: 저주, 약화) → 암흑마도사 (마딜+디버프: 생명력 흡수, 저주 폭발)
- 결계술사 (마탱: 아군에게 보호막, 마법 반사) → 대결계사 (마탱: 전체 보호막, 1회 피해 무효 결계)

## 성직자 (교회)
1차 견습 사제 (힐)
- 사제 (힐: 단일·광역 회복, 정화) → 대사제 (힐: 부활, 지속 회복 오라)
- 수도승 (회탱/근딜: 맨손 연타, 자가 회복, 회피) → 권성 (근딜: 기 폭발, 연타 마무리)
- 심판관 (방탱+근딜: 언데드·악마 특효, 성스러운 철퇴) → 이단심문관 (근딜+디버프: 봉인, 신성 화형)

## 히든 직업 (조건 전직, 시트 1장씩)
- 마검사: 전사·마법 계열 둘 다 레벨 20 이상
- 드루이드: "숲의 아이" 특성 + 사제 또는 사냥꾼
- 사령술사: 흑마법사 + 던전 "망자의 묘" 클리어
- 음유시인: "노래" 취미 + 모든 직업군 동료가 친밀도 50 이상
- 연금술사: "손재주" 특성 + 마을 연구소 건설
- 정령사: 마력 잠재력 A 이상 + 정령 이벤트

## 주인공 세진 (전용, 시트 1장)
이방인 → 통솔자(1차) → 군사(2차) → 영주(3차) → 이계의 개척자(히든)
- 전투력은 낮음. 지휘 오라, 지휘 게이지 스킬, 인물 파악(잠재력 열람)을 가짐.

## 이미지 규칙
- Codex 시트: 1536x1024, 3열 × 2행(칸당 512x512), #FF00FF 배경, 오른쪽을 보는 3/4 시점 도트.
- 같은 계열의 모든 시트에서 같은 칸 번호는 같은 사람(외모 고정). 그래서 전직해도 같은 인물로 보임.
- 계열마다 고유한 6명(identity 1~6)을 둠. 프롬프트는 codex_prompts.md 참고.
