# 무한 파고들기 시스템 (디스가이아 계열, v1 2026-10-27)

목표: 메인 스토리(귀환의 단서)가 끝난 뒤에도 숫자가 끝없이 커지는 성장. 모든 시스템은 세계관 안에서 설명됨.

## 1. 레벨 9999 + 윤회의 샘 (환생)
- 레벨 상한 9999. 경험치 곡선은 완만하고, 후반 던전은 적 레벨도 수천 단위. 데미지는 수백만까지 표기(1.2M 같은 단위).
- 마을 뒤 산에서 발견하는 "윤회의 샘"(스토리 해금). 레벨 100 이상이면 환생 가능 → 레벨 1로 돌아감. 대신 아래를 얻음:
  - 환생 보너스: 환생 직전 레벨의 일정 비율이 기본 능력치에 영구 누적("축적치").
  - 환생 포인트: 잠재력 등급 올리기, 직업 변경, 특성 다시 뽑기·고정에 사용.
  - 환생 횟수 표시(★1, ★2...). 높을수록 해금되는 히든 직업과 칭호가 있음.
- 같은 캐릭터를 여러 계열로 돌려 키우는 것이 핵심 루프.

## 2. 무기 숙련 + 스킬 계승
- 무기 종류별 숙련도(검, 창, 활, 지팡이, 맨손...) 0~99. 숙련도가 오르면 그 무기의 공용 스킬을 얻음.
- 직업 스킬은 익히면 영구 습득. 환생 후 다른 직업이어도 계승 슬롯(환생 횟수만큼 늘어남)에 장착 가능.
  - 예: 결투가의 회피 반격 + 성기사의 자가 치유 = 불사 회피탱.
- 스킬 레벨 1~99, 사용할수록 오름.

## 3. 장비의 기억 (아이템계)
- 모든 장비 안에는 "기억의 층"이 있음. 이세계의 물건에는 만든 이와 쓴 이의 기억이 깃들어 있다는 설정.
- 장비를 골라 들어가면 랜덤 생성 층(10층마다 보스: "기억의 수호자"). 한 층을 깰 때마다 그 장비의 레벨 +1, 능력치가 오름. 장비 레벨 상한은 희귀도에 따라 100~300.
- 장비 안에는 깃든 정령이 있음(디스가이아 이노센트에 해당):
  - 예: "근력의 정령 Lv12", "치명의 정령 Lv40"
  - 층 안에서 반항하는 정령을 쓰러뜨리면 복종 → 다른 장비로 옮기거나 합칠 수 있음(같은 종류끼리 수치 합산).
  - 희귀 정령: "경험치 2배", "환생 포인트 +", "전리품 +".
- 희귀도: 일반 / 고급 / 희귀 / 전설 / 이계(세진의 세계에서 넘어온 물건, 예: 볼펜, 손목시계, 스마트폰 — 메인 스토리 단서이자 최강 장비)

## 4. 영지 회의 (암흑의회 대응)
- 마을 대표자 회의에 안건을 올리면 대표들이 투표함. 대표는 주민과 고용 동료 중에서 뽑히고, 각자 성격·호감·세진 친밀도에 따라 찬반을 정함.
- 설득: 선물(물자), 설득 대사, 친밀도 이벤트. 부결되면 "힘으로 밀어붙이기"(대표들과 전투, 이기면 가결되지만 민심 하락).
- 안건 예시:
  - 고급 모험가 초빙
  - 상점 품목 강화
  - 적 강화 / 약화(경험치 배율 변화)
  - 경험치 2배 축제
  - 새 던전 개방
  - 장비 기억 층수 상한 확장
  - 환생 비용 할인
  - 특별 동료 모집

## 5. 무한 심연 (엔드 던전)
- 스토리 후반에 열리는 "세계의 틈": 층이 끝없이 이어짐. 100층마다 이계의 보스(세진의 세계와 이어진 존재).
- 층이 깊어질수록 적 레벨이 지수적으로 상승하고, 특수 규칙 층(회복 불가, 후열 봉인, 속도 2배...)이 섞임.
- 주간 기록, 최고 도달층 칭호.

## 6. 전투 숫자 연출
- 큰 숫자: 1,234 → 12.3K → 1.23M → 1.23B. 치명타 숫자는 금색 + 흔들림.
- 연쇄 콤보: 같은 대상을 연속으로 때리면 콤보 배율 표시.
- 과잉 피해(Overkill) 보너스: 남은 HP를 크게 넘기면 전리품 +.

## 7. 수집과 도감
- 몬스터 도감(처치 수에 따라 정보와 특효 개방), 장비 도감, 정령 도감, 칭호 도감. 각 도감의 달성률 보상 = 영구 보너스.

## 8. 스토리 이후 루프
메인 스토리 → 윤회의 샘 → 장비의 기억 → 영지 회의 확장 → 무한 심연 → 숨겨진 보스("귀환의 문지기", 레벨 9999) → 엔딩 분기(귀환 / 영지에 남기 / 두 세계를 잇기)
