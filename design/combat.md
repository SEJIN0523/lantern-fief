# 전투 설계 (v1, 2026-10-27)

## 화면
- 가로 사이드뷰 JRPG: 왼쪽 아군, 오른쪽 적. 폰 세로화면이면 위쪽 절반이 전장, 아래쪽은 로그/지휘 버튼.
- 각 진영은 2열 × 5줄(lane) = 10칸: 전열 5칸 + 후열 5칸.
- 파티는 최대 5명, 10칸 중 아무 데나 자유 배치. 세진도 파티 슬롯을 1칸 쓴다(넣으면 지휘 오라 발동, 빼면 마을 업무 보너스).
- 캐릭터 이미지는 정지 이미지(Codex 시트에서 잘라낸 것). 아군은 원본(오른쪽 보기), 적은 좌우 반전.

## 정지 이미지로 연출하기 (CSS transform + 캔버스 이펙트)
- 대기: 숨쉬기(scaleY 1.00↔1.02, 2초 주기, 캐릭터마다 위상 다르게), 발밑 그림자 타원.
- 근접 공격: 대상 앞까지 빠르게 미끄러짐 → 살짝 앞으로 기울기(rotate 8°) → 베기 궤적 이펙트 → 원위치 복귀.
- 원거리: 반동으로 뒤로 젖힘 → 투사체(화살/구체)가 포물선이나 직선으로 날아감.
- 마법: 시전자 발밑에 마법진 + 위로 떠오름 → 대상 칸에 이펙트.
- 피격: 흰색 번쩍(brightness 필터) + 좌우 흔들림 + 데미지 숫자 튀어오름. 치명타면 숫자 크게, 화면 흔들림, 잠깐 슬로우.
- 회피: 뒤로 반 칸 스텝 + 잔상 + "MISS". 막기: 방패 불꽃 + "GUARD".
- 필살기: 화면 어둡게 → 캐릭터 상반신 컷인이 대각선으로 스치고 → 스킬 이름 배너.
- 전투불능: 회색 처리 + 뒤로 쓰러지듯 rotate(-80°) + 페이드. 적은 아래로 가라앉으며 사라짐.
- 버프/디버프: 머리 위 작은 아이콘, 오라 색 글로우(drop-shadow).
- 배속: 1x / 2x / 4x / 결과만 보기.

## 턴 진행
- 속도 기반 타임라인(CTB): 상단 바에 다음 행동 순서를 초상 아이콘으로 표시. 행동할 때마다 다음 차례까지의 대기 = 100 / 속도.
- 자동전투. 플레이어가 개입할 수 있는 것:
  - 작전 지시(언제든 변경): 전원 공격 / 보스 집중 / 생존 우선 / 마력 아끼기
  - 세진의 지휘 스킬: 지휘 게이지가 차면 직접 발동(예: "전열 사수!", "집중 사격!", "후퇴!")

## 진형 규칙
- 근접 공격: 적 전열만 노림(같은 줄 우선, 그다음 인접 줄). 전열이 전멸하면 후열까지 닿음.
- 관통(창/일부 스킬): 한 줄의 전열과 후열을 동시에 때림.
- 원거리/마법: 아무 칸이나 노림. 단, 원거리 직업이 전열에 서면 명중 -15%.
- 범위 모양: 단일 / 한 줄(전후열) / 한 열(5칸) / 십자 / 3줄 / 전체.
- 후열은 근접에 안전한 대신, 후열 근접 직업은 공격하지 못하고 "대기"함(돌진·도약 스킬은 예외).
- 보호:
  - 수호: 같은 줄 후열 아군이 받을 공격을 대신 받음
  - 방벽: 인접 줄 전열 아군의 피해를 줄여 줌
  - 도발: 적의 단일 공격을 끌어옴
- 적 AI: 위협 수치(도발, 받은 피해, 직업 기본값)로 가중치를 매겨 대상을 고르고, 체력이 낮은 대상을 약간 선호함. 보스는 고유 패턴.

## 전투 후
- 전투불능 = 부상(며칠 휴식 필요). 이미 부상인 채로 다시 쓰러지면 중상 → 사망 판정(난이도 옵션: 사망 없음 / 낮음 / 하드코어).
- 드물게 흉터 특성이 붙음(예: "얼굴의 흉터": 위압 +, 매력 -).
