# 캐릭터 설계 (v1, 2026-10-27)

## 스탯
- 기본 능력치 6개: 근력, 체력, 민첩, 지력, 정신, 행운
- 파생 능력치: HP, 물리공격, 마법공격, 방어, 저항, 속도, 명중, 회피, 치명
- 직업이 성장 보정과 파생식 가중치를 정함. 레벨업할 때 오르는 양 = 직업 보정 × 잠재력 등급 × 개화 곡선.

## 잠재력 (숨김)
- 능력치마다 잠재력 등급이 있음: F / E / D / C / B / A / S, 그리고 극히 드물게 ★(규격 외)
  - 등급이 성장량과 상한을 정함.
- 종합 재능: 모든 등급의 평균. 히든 직업 조건에도 쓰임.
- 개화 시기(숨김):
  - 조숙형: 초반에 빠르게 크고 일찍 멈춤
  - 평범형
  - 대기만성형: 30레벨부터 성장이 폭발함
- 숨겨진 적성: 특정 히든 직업 적성 플래그(예: "정령과 공명").

### 공개 단계: ??? → 대략(낮음/보통/높음) → 등급 → 정확한 성장치
알아내는 방법:
1. 세진의 인물 파악: 직업 레벨이 오를수록 더 깊이 보임. 세진의 이세계 능력이 "사람을 알아보는 눈"이라는 설정.
2. 함께한 시간: 친밀도와 함께 출전한 횟수에 따라 대사 힌트가 나옴(예: "저 녀석, 활 쏘는 손이 남다른데").
3. 감정사: 유료로 능력치 하나의 등급을 공개(마을에 감정소를 지으면 할인).
4. 훈련장: 훈련 결과가 "기대 이상 / 이하"로 표시돼 간접적으로 드러남.
5. "눈썰미" 특성을 가진 동료가 다른 동료의 잠재력 힌트를 줌.

### 잠재력 변동
- 각성: 전멸 직전 생존, 특성 이벤트, 숙적 처치 등으로 등급 +1.
- 노력가 특성: 훈련 효율 +, 낮은 등급 한계를 넘어섬.
- 희귀 아이템(별의 이슬 등).
- 숨은 원석: 마을 주민 중 낮은 확률로 S나 ★가 섞여 있음. 싼 평민을 키워 볼 이유가 생김.

## 캐릭터 설정(특성)
생성 시 붙는 것:
- 성격 1 (필수)
- 취미 1
- 출신 1
- 특이 0~1 (희귀)
- 사연 0~1 (희귀, 메인 스토리 떡밥 가능)
특성마다 스탯 보정, 패시브, 액티브, 마을 업무 보정, 대사 톤이 붙음.

### 성격 (전투 대사와 AI 성향에도 영향)
- 용감함: 전열이면 공격 +10%, 체력이 낮아도 후퇴하지 않음
- 겁쟁이: 후열이면 회피 +15%, 전열이면 명중 -10%. "용기를 낸 자"로 진화 가능
- 냉정함: 치명 +5%, 혼란·공포 저항
- 다혈질: 피격 시 20% 확률로 분노(공격 +, 방어 -)
- 상냥함: 회복량 +15%, 인접 아군의 사기 +
- 허세꾼: 전투 시작 시 도발(자동). 쓰러지면 사기 -
- 게으름: 피로 회복 +, 속도 -5%. 액티브 "본기 발휘"(전투당 1회 2연속 행동)
- 노력가: 훈련 효율 +30%, 잠재력 한계 돌파
- 낙천가: 부상 회복 2배, 사기 하락 무시
- 의심 많음: 함정 감지, 기습 무효
- 충직함: 세진과 같은 파티면 모든 능력 +5%, 충성 하락 없음
- 탐욕스러움: 전리품 +20%, 급여 요구 +
- 고독을 즐김: 파티가 3명 이하이면 능력 +15%
- 수다쟁이: 친밀도 상승 2배, 은신 불가

### 취미 (주로 마을 업무와 전투 외 보너스)
- 요리: 식당 효율 +, 원정 중 식사 버프
- 낚시: 식량 +, 인내(지속 버프 시간 +)
- 노래: 술집 수입 +, 액티브 "응원가"(아군 사기 +)
- 독서: 지력 경험치 +, 연구소 효율 +
- 도박: 행운 +, 액티브 "운명의 주사위"(랜덤 대박 또는 꽝)
- 대장일: 대장간 효율 +, 장비 내구도 유지
- 원예: 농장 +, 약초 채집 +
- 술: 피로 회복 +, 다음 날 아침 속도 -
- 동물 돌보기: 짐승형 몬스터에게 위협받는 정도 -, 목장 +
- 훈련광: 쉬는 날에도 경험치 획득, 피로 +
- 그림: 정찰 시 던전 지도 정보 +
- 손재주: 함정·장치 해제, 연금술사 히든 조건

### 출신 (기본 스탯 보정)
- 농가 출신: 체력 +, 농업 +
- 귀족의 서자: 매력·지력 +, 급여 요구 +
- 전쟁 고아: 근력 +, 충성이 오르기 어려움
- 떠돌이: 민첩 +, 원정 피로 -
- 산사람: 행군 +, 숲 지형 보너스
- 도시 빈민가: 훔치기·회피 +
- 신전 고아원: 정신 +, 언데드 저항
- 몰락한 기사 가문: 방어 +, "가문 재건" 개인 퀘스트

### 특이 (희귀)
- 쌍둥이 기억: 다른 쌍둥이가 어딘가 있음(이벤트)
- 마력 체질: 마력 잠재력 +1등급, 몬스터를 끌어들임
- 불사신 같은 운: 전투당 1회 치명상 생존
- 엘프의 피 1/4: 수명 길고 활 적성
- 거구: HP +20%, 회피 -
- 왼손잡이 검객: 반격 확률 +
- 야맹증 / 밤눈: 야간 습격에서 능력 - / +
- 눈썰미: 동료 잠재력 힌트
- 숲의 아이: 드루이드 조건
- 이상한 꿈: 이세계의 비밀과 연결(메인 스토리 떡밥)

### 사연 (희귀, 개인 퀘스트)
- 복수할 상대가 있음: 특정 몬스터나 인물에게 특효, 퀘스트 완료 시 각성
- 잃어버린 동생을 찾음
- 빚쟁이에게 쫓김: 급여 요구 +, 가끔 빚쟁이 이벤트
- 왕국 기사단 탈영병: 왕국 관련 이벤트에서 분기
- 세진처럼 "다른 세계에서 온 물건"을 갖고 있음: 메인 스토리 단서

## 관계 시스템
- 친밀도: 동료 ↔ 세진, 동료 ↔ 동료. 함께 출전, 같은 마을 업무, 이벤트로 오름.
- 궁합: 성격 조합(예: 용감함+겁쟁이 = "지켜주는 관계", 다혈질+냉정함 = 라이벌).
- 연계기: 친밀도 높은 둘이 인접한 칸에 있으면 합동기 발동(예: 기사+사제 "성스러운 방벽").
- 라이벌: 같은 파티면 둘 다 공격 +, 쉬는 날 다툼 이벤트.
- 충성: 용병은 계약(일당). 충성이 일정 이상이면 "영지 기사단"으로 정식 편입(급여 -, 능력 +).

## 칭호 (업적 자동 부여)
- 고블린 100마리 처치 → "고블린 도살자"(고블린 특효)
- 회피 500회 → "바람"
- 아군 1000회 수호 → "마을의 벽"
- 한 번도 쓰러지지 않고 50전 → "불패"

## 사기와 피로
- 사기: 승리, 연계, 마을 축제로 오르고 패배, 동료 부상, 급여 체불로 떨어짐. 행동 순서와 치명에 영향.
- 피로: 연속 출전으로 쌓임. 마을 숙소, 온천(시설), 휴식일로 회복.

## 영입 경로
- 모험가 길드: 즉시 전력이지만 일당이 비싸고 충성이 낮음. 1차~2차가 등장.
- 병사 모집: 창병 고정, 싸고 충성 높음. 마을 인구가 필요함.
- 마을 주민 자원: 평민, 아주 싸지만 약함. 잠재력은 랜덤(숨은 원석).
- 구출/이벤트: 던전 포로, 떠돌이 고유 인물(고정 설정).
- 명성: 마을 명성이 오르면 더 높은 등급의 모험가가 찾아옴.

## 장비 (v2, 2026-10-27)
- 무기는 갈아 끼우지 않는다. 캐릭터마다 고유 무기 1개(이미지에 그려진 그 무기, 사람마다 고유 문양·색)를 갖고 끝까지 키운다.
  - 무기 종류는 직업을 따라 바뀜(전직하면 같은 문양의 새 형태로 "재단조").
  - 강화: 숫돌·강화석 → +1~+99. 단계마다 성공률이 있고, 실패해도 파괴는 없음(+단계 유지, 재료만 소모).
  - 룬 슬롯: 강화 단계에 따라 1~5개. 속성 룬이나 효과 룬을 끼움.
  - 각성: +20, +40, +60에서 무기 이름을 짓고 고유 패시브 1개 획득(캐릭터 특성과 연동, 예: 용감함 → "선봉의 맹세").
  - 장비의 기억(아이템계): 고유 무기 속으로 들어가 층을 깨면 무기 레벨 상승, 정령 획득. 사실상 무기 성장이 파고들기의 중심.
- 장착 슬롯: 방어구 1(몸), 장신구 2. 방어구·장신구는 드롭·상점·제작으로 얻고 갈아 끼운다. 방어구는 수치만 바뀌고 외형은 직업 그림 그대로.
- 이계 유물(볼펜, 스마트폰 등)은 장신구 슬롯용 최상급 장신구.
