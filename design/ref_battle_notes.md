# 참고: 「잔향의 성채 · 자동 전투 연구실」에서 가져올 것 (2026-10-27)

원본: design/ref/ (Phaser 3 프로토타입, 440×500 캔버스, 6 대 6, 전열 3·후열 3)

## 가져올 것
1. 발 기준점(foot anchor): 그림마다 footX/footY(발 중앙 위치 비율)와 bodyRatio(몸 높이 비율)를 기록해 두고, 모든 캐릭터를 같은 키로 맞춰 발을 바닥선에 정확히 세운다.
   → 우리 시트 자르기 도구가 자를 때 자동 계산해서 ART 메타로 저장
2. 깊이 정렬: y(줄)가 클수록 앞에 그림. 공격하러 나갈 때는 맨 앞으로 올렸다가 돌아오면 복귀
3. 근접 공격 리듬:
   - 뒤로 9px 반동(130ms) → 대상 앞까지 돌진(220ms, ease-in)
   - 직업별 베기 모양: 검 = 호, 창 = 세 줄 찌르기, 기사 = 방패 타원
   - 타격 후 330ms에 제자리 복귀
4. 원거리: 활을 6° 젖힘 → 화살이 대상에게 직선으로 날아가며 빛 꼬리 파티클
5. 마법: 발밑 마법진(타원 2겹 + 육망성)이 커졌다 줄어듦 → 시전 파티클 → 빛 구체 → 대상 위치에서 고리가 퍼짐
6. 회복: 발밑 문양 → 빛 덩어리가 날아감 → 대상 발밑 고리 + 위로 떠오르는 십자 + 초록 숫자
7. 피격:
   - 하얗게 채우기(tintFill)
   - 넉백: 9px 두 번 흔들림 → 13px 밀림 → 제자리 복귀
   - 불꽃 파티클
8. 강공격(3번째 행동마다):
   - 히트스톱 85ms(모든 움직임 정지) → 화면 흔들림 180ms + 짧은 주황 플래시
   - 숫자를 크게, 앞에 ✦ 표시
9. 숫자: 굵은 세리프 + 테두리, 위로 34px 떠오르며 사라짐
10. 분위기: 바닥 타원 무대, 아이소메트릭 바닥 무늬, 횃불 깜빡임, 떠다니는 먼지 파티클
11. 화면 구성:
    - 전투 옆(폰에서는 아래)에 아군 HP 목록 패널
    - 시간이 찍힌 전투 로그(최근 7줄)
    - 작전(균형 / 집중 공격 / 수비), 도주 버튼, 결과 오버레이
12. 효과음: WebAudio로 짧은 톤을 즉석 생성(타격 = 삼각파, 마법 = 사인파). 기본은 끄고 토글로 켬

## 가져오지 않을 것
- Phaser 라이브러리(1.2MB): 우리는 DOM + WAAPI로 같은 연출을 구현 가능. 파티클만 가벼운 캔버스 레이어로 추가
- 아군·적 번갈아 고정 순서로 행동: 우리 속도 기반 타임라인이 더 전략적이라 유지
- 3번째마다 강공격 규칙: 우리는 치명타·스킬로 같은 강조를 표현(히트스톱 연출만 가져옴)
